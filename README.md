### Hi there, I'm Sajjad 👋

I'm a front-end developer who loves building clean, user-centric experiences. For me, the best part of this work is bridging the gap between a human need and a technical solution.

For the last few years, I took a bit of a different path. I founded and ran **Ceramic Catalysts**, a small tech agency for the auto detailing industry. It was an incredible journey that taught me everything about the business side of tech—from talking to clients and understanding their real-world problems to owning a project from start to finish. Along the way, I discovered my real passion wasn't just in *selling* the solution, but in the craft of *building* it.

So, after graduating, I decided to go all-in on what I love most: bringing ideas to life with code.

### A Few Things I've Built 🚀

-   **[Nomad-Score](https://nomad-score.com)**: A full-stack discovery platform I architected to help digital nomads find hotels with verified Wi-Fi speeds. This was a deep dive into database design, API integration, and complex, multi-layered filtering.
-   **[Simple Phonics](https://phonics.sajjadhaq.com)**: An interactive learning app that taught me a ton about solving tricky UI challenges, like native-like mobile gestures and supporting right-to-left (RTL) languages.

### What's On My Mind Lately 🤔

I'm fascinated by the intersection of AI and developer workflow. Tools like Cursor and GitHub Copilot are changing *how* we build, and I'm always thinking about how to leverage them to focus more on creative problem-solving and less on boilerplate. I'm also exploring how we can build more accessible and performant applications without getting lost in framework complexity.
